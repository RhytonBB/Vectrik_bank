# Настройка клиентской части Vektrik Bank

## Обзор изменений

Клиентская часть была полностью переработана для работы только на мобильных устройствах и планшетах. Основные изменения:

### Backend изменения:
1. **Новое поле в БД**: Добавлено поле `account_number` в таблицу `users`
2. **Новые API endpoints**:
   - `/api/client/banners` - получение активных баннеров
   - `/api/client/products` - получение активных товаров
   - `/api/client/purchase` - покупка товаров
   - `/api/client/purchases` - покупки пользователя
   - `/api/client/transactions` - транзакции пользователя

### Frontend изменения:
1. **Новая навигация**: Нижняя навигация с иконками
2. **Новые страницы**:
   - `/client` - главная страница
   - `/client/store` - магазин
   - `/client/news` - новости (пока пустая)
   - `/client/about` - о нас
   - `/client/profile` - профиль пользователя
3. **Проверка устройства**: Клиентская часть доступна только с мобильных устройств

## Установка и настройка

### 1. Обновление базы данных

Выполните SQL миграцию для добавления поля `account_number`:

```sql
-- Выполните файл migrations/add_account_number.sql
ALTER TABLE users ADD COLUMN account_number VARCHAR(8) UNIQUE NOT NULL DEFAULT '00000000';
CREATE INDEX idx_users_account_number ON users(account_number);
```

### 2. Обновление существующих пользователей

Запустите скрипт для генерации номеров счетов существующим пользователям:

```bash
cd scripts
go run update_account_numbers.go
```

### 3. Пересборка frontend

```bash
cd vektrik-frontend
npm install
npm run build
```

### 4. Перезапуск сервера

```bash
cd cmd/server
go run main.go
```

## Функциональность

### Главная страница (`/client`)
- Отображение баннера (если есть активные)
- Информация о счете и балансе
- Список покупок пользователя
- История транзакций

### Магазин (`/client/store`)
- Список активных товаров
- Возможность покупки товаров
- Проверка баланса перед покупкой
- Обновление остатков товаров

### О нас (`/client/about`)
- Контактная информация
- Адреса офисов
- Политика конфиденциальности

### Профиль (`/client/profile`)
- Информация о пользователе
- Номер счета
- Статус аккаунта
- Кнопка выхода

## Ограничения

1. **Доступ только с мобильных устройств**: Клиентская часть недоступна с компьютеров
2. **Админы не могут использовать клиентскую часть**: Автоматическое перенаправление в админку
3. **Обычные пользователи не могут использовать админку**: Автоматическое перенаправление в клиентскую часть

## Тестирование

1. Откройте приложение на мобильном устройстве или используйте DevTools браузера в режиме мобильного устройства
2. Войдите как обычный пользователь (не админ)
3. Проверьте все разделы клиентской части
4. Попробуйте купить товар в магазине
5. Проверьте отображение покупок и транзакций

## API Endpoints

### Клиентские API (только для обычных пользователей)
- `GET /api/client/banners` - активные баннеры
- `GET /api/client/products` - активные товары
- `POST /api/client/purchase` - покупка товара
- `GET /api/client/purchases` - покупки пользователя
- `GET /api/client/transactions` - транзакции пользователя

Все клиентские API проверяют, что пользователь не является админом.
