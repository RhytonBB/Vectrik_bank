# Функционал Админки Vektrik Bank

## Обзор
Админка представляет собой веб-интерфейс для управления системой Vektrik Bank, построенную на Vue.js 3 с backend на Go. Доступ к админке имеют только пользователи с правами администратора.

## Структура проекта
- **Backend**: Go (Gin/Gorilla Mux)
- **Frontend**: Vue.js 3 + Element Plus
- **База данных**: PostgreSQL
- **Telegram Bot**: Python (aiogram)

---

## 🔐 Аутентификация и авторизация

### Вход в систему
- **URL**: `/login`
- **Методы**: GET (форма), POST (авторизация)
- **Поддержка**: JSON и HTML формы
- **Безопасность**: JWT токены с HTTP-only cookies

### Проверка прав
- Все API endpoints проверяют JWT токен
- Проверка флага `is_admin` для доступа к админ-функциям
- Автоматический редирект на `/login` при отсутствии токена

2. 👥 Модерация пользователей

## 💸 Начисление Вектриков

### URL: `/admin/reward`

#### Функционал:
- **Поиск пользователей** по имени, фамилии или Telegram username
- **Массовое начисление** - выбор нескольких пользователей
- **Настройка суммы** начисления
- **Выбор причины**: drop, активность, награда
- **Дополнительный контекст** (опционально)

#### API Endpoints:
- `GET /api/admin/reward/users?q=query` - поиск пользователей
- `POST /api/admin/reward` - начисление вектриков

#### Логирование:
- Все операции записываются в `AdminLog`
- Сохраняется информация о админе, пользователе, сумме и контексте

---

## 👥 Модерация пользователей

### URL: `/admin/users`

#### Основной функционал:
- **Просмотр списка** всех пользователей
- **Фильтрация** по балансу (мин/макс)
- **Поиск** по имени, фамилии, Telegram username
- **Массовые операции** с балансом

#### Детальная информация о пользователе:
- **URL**: `/admin/users/{id}`
- **Личные данные**: имя, фамилия, Telegram username
- **Статистика**: баланс, дата регистрации
- **История транзакций** с детализацией
- **История покупок** товаров/лотов

#### Управление пользователями:
- **Активация/деактивация** аккаунта
- **Назначение/снятие** прав администратора
- **Бан/разбан** пользователя
- **Редактирование** личных данных
- **Удаление** пользователя
- **Корректировка баланса** с указанием причины

#### API Endpoints:
- `GET /api/admin/users` - список пользователей
- `POST /api/admin/users` - создание пользователя
- `GET /api/admin/users/{id}` - детали пользователя
- `PUT /api/admin/users/{id}` - редактирование
- `DELETE /api/admin/users/{id}` - удаление
- `POST /api/admin/users/{id}/activate` - активация
- `POST /api/admin/users/{id}/admin` - права админа
- `POST /api/admin/users/{id}/ban` - бан
- `POST /api/admin/users/{id}/unban` - разбан

## 📢 Рассылка через Telegram-бота

### URL: `/admin/broadcast`

#### Создание сообщений:
- **Текст сообщения** с поддержкой HTML-разметки
- **Загрузка медиафайлов**: изображения, видео, документы
- **Превью медиа** перед отправкой
- **Выбор целевой аудитории**:
  - Всем пользователям с Telegram ID
  - Только зарегистрированным
  - Выбор конкретных пользователей вручную

#### История отправки:
- **Список всех сообщений** с датой создания
- **Статус отправки**: ожидает, отправляется, завершено, ошибка
- **Статистика**: количество отправленных/неотправленных
- **Детальная история** по каждому сообщению:
  - Список получателей
  - Статус доставки каждому
  - Ошибки отправки (если есть)

#### Технические особенности:
- **Асинхронная отправка** в фоне
- **Интеграция с Telegram Bot API**
- **Отправка медиа с подписью** в одном сообщении
- **Обработка ошибок** и повторные попытки

#### API Endpoints:
- `GET /api/admin/broadcast` - история сообщений
- `POST /api/admin/broadcast` - создание сообщения
- `GET /api/admin/broadcast/{id}/history` - детальная история
- `GET /api/admin/broadcast/users?type=all|registered` - список пользователей

## 🛍️ Управление лотами и товарами

### URL: `/admin/products`

#### Основной функционал:
- **Просмотр списка** всех товаров/лотов
- **Фильтрация** по типу, статусу активности
- **Сортировка** по дате создания, цене, остатку

#### Создание товара:
- **Название** и описание
- **Цена** в вектриках
- **Тип товара**: regular, drop, shared
- **Остаток** на складе
- **Загрузка медиафайлов** (фото товара)
- **Статус активности**

#### Редактирование товара:
- **URL**: `/admin/products/edit/{id}`
- **Изменение всех параметров**
- **Замена медиафайлов**
- **Удаление товара**

#### API Endpoints:
- `GET /api/admin/products` - список товаров
- `POST /api/admin/products` - создание товара
- `GET /api/admin/products/{id}` - детали товара
- `PUT /api/admin/products/{id}` - редактирование
- `DELETE /api/admin/products/{id}` - удаление
- `POST /api/admin/products/upload` - загрузка медиа

## 📈 Аналитика

### URL: `/admin/analytics`

#### Основные метрики:
- **Общее количество пользователей**
- **Активные пользователи**
- **Забаненные пользователи**
- **Общий баланс системы**
- **Новые пользователи** за период
- **Сумма трат** (отрицательные транзакции)
- **Сумма начислений** (положительные транзакции)

#### Детальная аналитика:
- **Динамика по дням** - траты и начисления
- **Топ-10 по тратам** - самые активные покупатели
- **Топ-10 по начислениям** - получатели наград
- **Последние 10 транзакций** с детализацией

#### Фильтрация:
- **По пользователю** - конкретный пользователь
- **По периоду** - с/по дату
- **По типу операций** - траты/начисления

#### API Endpoints:
- `GET /api/admin/analytics` - общая статистика
- `GET /admin/analytics` - HTML страница с графиками

## 🔧 Технические особенности

### Безопасность:
- **JWT токены** с HTTP-only cookies
- **Проверка прав** на все операции
- **Валидация данных** на backend и frontend
- **Логирование** всех административных действий

### Медиафайлы:
- **Хранение** в папке `internal/media/`
- **Статический сервер** для раздачи файлов
- **Proxy настройки** для frontend
- **Поддержка** изображений, видео, документов

### База данных:
- **PostgreSQL** с GORM ORM
- **Миграции** автоматические при запуске
- **Связи между таблицами** (foreign keys)
- **Индексы** для оптимизации запросов

### Telegram интеграция:
- **Bot Token** из переменных окружения
- **Отправка медиа** с подписями
- **Обработка ошибок** API
- **Асинхронная отправка** больших объемов

## 🚀 Запуск системы

### Переменные окружения:
```env
DATABASE_URL=postgres://username:password@localhost:5432/vectrik_bank
JWT_SECRET=your_secret_key_here
BOT_TOKEN=your_telegram_bot_token_here
BASE_URL=http://localhost:8080
PORT=8080
```

### Порядок запуска:
1. **База данных** PostgreSQL
2. **Backend**: `go run cmd/server/main.go`
3. **Frontend**: `npm run serve` (из папки vektrik-frontend)
4. **Telegram Bot**: `python bot/main.py` (опционально)

### Доступ:
- **Админка**: http://localhost:8081/admin/dashboard
- **API**: http://localhost:8080/api/
- **Медиафайлы**: http://localhost:8080/internal/media/
