# Массовая регистрация пользователей

## Описание
Система поддерживает массовую регистрацию пользователей через загрузку файлов CSV или Excel.

## Поддерживаемые форматы
- **CSV** (.csv)
- **Excel** (.xlsx, .xls)

## Структура файла

### Обязательные колонки:
1. **Имя** - может называться: "Имя", "First Name", "FirstName", "Name"
2. **Фамилия** - может называться: "Фамилия", "Last Name", "LastName", "Surname"
3. **Telegram Username** - может называться: "Telegram", "Telegram Username", "Username", "TG", "Telegram_Username"

### Пример CSV файла:
```csv
Имя,Фамилия,Telegram Username
Иван,Иванов,ivan_ivanov
Мария,Петрова,maria_petrova
Алексей,Сидоров,alex_sidorov
```

### Пример Excel файла:
| Имя | Фамилия | Telegram Username |
|-----|---------|-------------------|
| Иван | Иванов | ivan_ivanov |
| Мария | Петрова | maria_petrova |
| Алексей | Сидоров | alex_sidorov |

## Использование

### 1. Перейдите на страницу регистрации пользователей
- Откройте админ-панель
- Перейдите в раздел "Модерация пользователей"
- Нажмите "➕ Зарегистрировать нового пользователя"

### 2. Выберите режим массовой регистрации
- Переключитесь на вкладку "Массовая регистрация"

### 3. Загрузите файл
- Перетащите файл в область загрузки или нажмите для выбора
- Поддерживаются файлы до 2MB

### 4. Предварительный просмотр
- Система покажет список пользователей, которые будут зарегистрированы
- Проверьте данные перед подтверждением

### 5. Подтверждение регистрации
- Нажмите "Зарегистрировать X пользователей"
- Система создаст всех пользователей и покажет результат

## Ограничения
- Максимум 1000 пользователей за один раз
- Размер файла не более 2MB
- Telegram username должен быть уникальным
- Все поля обязательны для заполнения

## Обработка ошибок
- Если в файле есть ошибки, система покажет их список
- Пользователи с ошибками не будут зарегистрированы
- Успешно зарегистрированные пользователи будут созданы

## Особенности
- Система автоматически убирает символ "@" из начала Telegram username
- Пустые строки и строки с недостающими данными игнорируются
- Проверяется уникальность Telegram username перед регистрацией
- Все новые пользователи создаются с статусом "Активен"

## Примеры ошибок
- "Row 5: telegram username 'ivan_ivanov' already exists" - пользователь с таким username уже существует
- "Row 3: missing required fields" - не заполнены обязательные поля
- "Required columns not found" - не найдены нужные колонки в файле
